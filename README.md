## Deskripsi Pengerjaan UTS

Aplikasi Pengelolaan Stok Barang pada Toko Tembakau merupakan aplikasi berbasis Android yang dikembangkan untuk membantu proses pengelolaan persediaan barang pada toko tembakau. Aplikasi ini dirancang agar pemilik toko dapat mengelola data barang, mencatat stok masuk, mencatat stok keluar atau penjualan, serta melihat laporan persediaan dan penjualan.

Aplikasi ini mendukung dua jenis satuan barang, yaitu kilogram (Kg) untuk produk tembakau dan bungkus untuk barang seperti gabes, kertas, dan perlengkapan lainnya.

Pengerjaan UTS ini berfokus pada pembuatan antarmuka dan implementasi fitur utama aplikasi sesuai kebutuhan pengelolaan stok barang toko tembakau.

## Fitur yang Diimplementasikan

Fitur aplikasi yang dikembangkan meliputi:

1. Splash Screen
Menampilkan halaman pembuka aplikasi sebelum pengguna masuk ke halaman login.

2. Login Admin
Menyediakan halaman autentikasi untuk admin sebelum mengakses aplikasi.

3. Dashboard Admin
Menampilkan halaman utama yang berisi ringkasan informasi stok barang dan menu navigasi aplikasi.

4. Data Barang
Menampilkan daftar barang yang tersedia di toko dengan pilihan satuan Kg atau Bungkus.

5. Tambah Barang
Direncanakan untuk menambahkan data barang baru ke dalam aplikasi.

6. Stok Masuk
Direncanakan untuk mencatat penambahan stok barang.

7. Stok Keluar atau Penjualan
Direncanakan untuk mencatat pengurangan stok berdasarkan transaksi penjualan.

8. Laporan Stok dan Penjualan
Direncanakan untuk menampilkan informasi persediaan dan transaksi penjualan.

## Persyaratan Menjalankan Aplikasi

Persyaratan

Laptop atau komputer.

Android Studio.

Android SDK.

Perangkat Android atau emulator.

Kabel USB jika menggunakan perangkat Android secara langsung.

## Cara Menjalankan Aplikasi

1. Buka Android Studio.

2. Pilih menu Open.

3. Cari dan pilih folder proyek TokoTembakau.

4. Tunggu proses Gradle Sync sampai selesai.

5. Hubungkan perangkat Android atau jalankan emulator.

6. Klik tombol Run pada Android Studio.

7. Tunggu proses instalasi dan aplikasi akan terbuka pada perangkat.
